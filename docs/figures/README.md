# Figures

Every PNG here is generated by the pipeline — nothing is hand-drawn.

    python reproduce.py

## What lives where

| Folder | Content | Regenerated by |
|---|---|---|
| eport/ | **fig01 … fig09** — the nine figures as they appear in the report (same panel layout, same labels) | src/report_figures.py |
| . (flat) | the five L3 analysis figures quoted in docs/L3_brief_note.md | src/l3_map.py |

The complete analysis set (L1 2×2 panel, five L2 panels, five L3 panels) is written to
output/ on every run and is git-ignored; the copies kept here are only the ones that are
referenced by the documents or that a marker may want to open without running Python.
