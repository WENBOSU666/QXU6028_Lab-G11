# Figures

Every PNG here is generated by the pipeline — nothing is hand-drawn.

    python reproduce.py

## What lives here

Everything tracked in this folder is the report figure set, in the same panel layout as the
report itself:

| Folder | Content | Regenerated by |
|---|---|---|
| 
eport/ | fig01 … fig09 | src/report_figures.py |

The wider analysis set — the L1 four-panel figure, the five L2 panels and the five L3 panels —
is written to output/ on every run and is git-ignored, because those panels are already
contained in the report figures above.
